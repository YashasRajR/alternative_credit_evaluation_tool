# Changelog

## 1.0.0 (10 November 2026)

First release.

- 100-point scorecard over ten alternative-data factors, with a reason for every point
- Default-risk model (logistic regression, synthetic training data) with per-farmer risk drivers
- Recommendation and loan limit capped at 40% of household income for all repayments
- Improvement plan showing the points each step would add
- Crop guidance from Kharif 2026-27 and Rabi 2027-28 MSPs
- Assessments page with band mix, totals and search
- Passbook-style design: ruled register paper, a score tape and an ink stamp for the recommendation, in English and Hindi
- Print or save any assessment as PDF
- 29 backend tests using an in-memory MongoDB
